# Объясняй наглядно

`explain-visually` — навык для ИИ-агентов, который выбирает способ объяснения
под вопрос: схему, график, интерактивную модель, пошаговый разбор или иллюстрацию.
Для простого вопроса достаточно короткого текстового ответа.

## Примеры

- «Покажи, как работает дыхание собаки» — схема движения воздуха и диафрагмы.
- «Как длина маятника влияет на период?» — модель с изменяемой длиной.
- «Разбери рекурсию» — стек вызовов и возвратов по шагам.
- «Объясни аутентификацию в этом проекте» — разбор текущего кода и схема входа,
  проверки запросов и обновления сессии.

Навык проверяет исходные факты, обозначает упрощения модели и использует доступные
средства показа. Для интерактивности нужны инструменты соответствующего агента.
Если их нет, он выбирает поддерживаемую статическую форму и сообщает об ограничении.

## Установка

Склонируйте репозиторий в каталог навыков своего агента. Например, для клиентов,
которые читают общий каталог `~/.agents/skills`:

```sh
git clone https://github.com/GlebKostousov/explain-visually.git ~/.agents/skills/explain-visually
```

Другие распространённые каталоги: `~/.claude/skills`, `~/.cursor/skills`
и `~/.grok/skills`. Используйте путь, который поддерживает ваш клиент.
Перезапустите клиент или обновите список навыков, если он не перечитывает его сам.

Основные инструкции находятся в [SKILL.md](SKILL.md). Навык допускает автоматический
выбор; его также можно вызвать по имени `explain-visually` в поддерживающем это клиенте.

## Инструменты

Обязательных внешних библиотек у навыка нет. Он выбирает из доступных инструментов:

- Markdown и Mermaid для таблиц и простых схем;
- `visualize` для интерактивных объяснений внутри чата;
- PlantUML для UML/C4 с учётом правил проекта;
- генератор изображений для растровых иллюстраций;
- инструменты построения графиков для точных экспортируемых фигур.

Поддержка каждого формата зависит от клиента. Навык не устанавливает плагины
и не публикует материалы без поручения пользователя.
